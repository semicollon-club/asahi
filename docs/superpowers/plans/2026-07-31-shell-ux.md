# 셸·프로세스 사용성 구현 계획

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 부원이 실제로 쓰는 셸·프로세스 경로에서 "실패로 보이는 것"을 없앤다 — 명령의 종료 코드를 도구 실패와 분리하고, 계속 도는 명령을 `proc_start` 로 유도하고, `proc_list` 에 사람 이름을 띄운다.

**Architecture:** 세 조각 모두 기존 이음매를 그대로 쓴다. 종료 코드는 `sh_exec` 실행기의 `close` 핸들러 한 곳, 도구 유도는 문구 두 곳, 이름 표시는 "어댑터가 저장 → 봇이 주입 → 워커가 렌더링" 3단계인데 각 단계의 자리(`getRole` 호출부, `onlyUserId` 주입 블록, `labelOf` 인자)가 이미 존재한다. 새 프로토콜 프레임도, 새 스키마도 만들지 않는다.

**Tech Stack:** TypeScript (ESM/NodeNext), Node.js, vitest, Postgres(pg / 테스트는 pg-mem), discord.js

- [ ] **Step 4: `describeExit` 순수 함수를 추가**

`agent/src/remote/executors.ts` 에서 `sh_exec` 실행기보다 위, 다른 모듈 수준 함수들 옆에 넣는다.

```ts
// sh_exec 의 본문 문구를 만든다. close 핸들러 안에 인라인으로 두면 문자열 조합만 따로 검증할
// 방법이 없어(자식 프로세스를 실제로 띄워야 한다) 순수 함수로 뺀다.
//
// 출력이 비었을 때 그 사실을 명시하는 이유: 빈 문자열만 돌려주면 모델은 "도구가 아무 말도
// 안 했다"와 "명령이 아무것도 출력하지 않았다"를 구분할 수 없다. 실사용에서 netstat|findstr 이
// 정확히 이 모양(빈 출력 + exit 1)이었고, 모델이 매번 문맥으로 추측해야 했다.
export function describeExit(out: string, code: number | null): string {
  const body = out.length > 0 ? out : "(출력 없음)";
  if (code === 0) return body;
  // code 가 null 이면 프로세스가 신호로 끝난 것이다(POSIX 에서 흔하다). "(종료 코드 null)" 은
  // 아무 정보도 주지 못하므로 무슨 일이 있었는지를 그대로 적는다.
  return code === null ? `${body}\n(신호로 종료됨)` : `${body}\n(종료 코드 ${code})`;
}
```

// 네트워크 프레임을 건너오므로, 형태가 어긋난 값(배열·null·중첩 객체·숫자 값)이 그대로
// 렌더링에 흘러들지 않게 여기서 걸러낸다 — str/num 이 있는 것과 같은 이유의 방어다.
function strMap(v: unknown): Record<string, string> {
  if (typeof v !== "object" || v === null || Array.isArray(v)) return {};
  const out: Record<string, string> = {};
  for (const [k, val] of Object.entries(v as Record<string, unknown>)) {
    if (typeof val === "string" && val.length > 0) out[k] = val;
  }
  return out;
}

Task 2 의 실제 효과(모델이 도구를 바꿔 고르는가)는 코드로 검증할 수 없다. 배포 후 `actions` 에서 `sh_exec` 타임아웃 건수가 줄어드는지로 확인한다.

```sql
select to_char(to_timestamp(ts/1000) at time zone 'Asia/Seoul','MM-DD HH24:MI') as t,
       tool, status, left(coalesce(input,''),60) as input
from actions
where tool = 'sh_exec' and result_summary like '%끝나지 않아%'
order by ts desc limit 20;
```
