# 로드맵

현재 상태(라이브·병합 기능·미완 항목)는 [STATUS.md](STATUS.md) 참고. 이 문서는 **다음에 무엇을
할 것인가**만 다룬다. 2026-09-22 판의 실측·코드상 원인·배제한 대안·결정 사항은
[사용성 로드맵 근거 문서](../superpowers/specs/2026-09-22-usability-roadmap-design.md)에 있다.

## 상위 테마 — 무엇을 만들고 있는가

2026-08-05 캐릭터 페르소나 제거([설계](../superpowers/specs/2026-08-05-remove-character-persona-design.md))로
**상위 테마가 바뀌었다.** 그전까지 이 문서는 "AI를 하나의 인격체로 느끼게" 만드는 인격체화 3축
(캐릭터·자기인지·능동성)으로 전체를 조직했는데, 그중 1축(캐릭터)을 통째로 걷어냈다. 남은 두 축을
"캐릭터가 발현되는 구체적 행동"으로 설명하던 근거도 함께 사라졌다 — **발현될 캐릭터가 없다.**

지금의 아사히는 기둥 둘이다.

1. **원격 개발 비서** — 디스코드에서 워커의 파일·셸·장기 실행 프로세스를 조종한다. 실제로 만들어진
   표면 중 가장 크다(원격 도구 11종, [아키텍처 개요](../architecture/overview.md)). 소유자는 2026-09-06
   부터 풀 하네스(미니PC 에서 Claude Code 통째로)로 간다.
2. **동아리 지식 저장소** — 공용 기억(`scope='shared'`)과 정기 게시. 캐릭터 제거 스펙이 "남는 핵심
   기능"으로 명시한 것이다.

**자기 관측**(자기인지·`actions` 기록)은 세 번째 기둥이 아니라 위 둘을 진단하는 가로축으로 취급한다.

## 지금의 사용 국면 — 부원 5명이 쓰고 있다 (2026-09-22 실측)

2026-08-07 판은 "소유자 단독 — 부원에게는 아직 열지 않았다"를 전제로 우선순위를 정했다. **이제
사실이 아니다.** 최근 30일 실측(근거 문서 §2):

| | 소유자 | 부원 |
|---|---|---|
| 인원 · 30일 활동 | 1 | 5 · **5명 전원** |
| 대화 / 사용자 발화 | 15 / 106 | 15 / 67 |
| 경로 | 하네스(`Bash` 303 · `Read` 152 · `Edit` 126 · 브라우저 ≈140) | 얇은 워커(`sh_exec` 165 · `fs_edit` 112 · `fs_read` 100 · `proc_*` 25) |
| 봇으로 만든 PR | — | 3 (병합 2) |
| 턴 길이 | 중앙값 1스텝·22초, **최대 127스텝·13.6분** | 중앙값 1스텝·10초, 최대 30스텝·6분 |

이 사실이 아래 우선순위를 지배한다.

- 부원 마찰은 "아직 실현되지 않은 위험"이 아니라 **이미 치르고 있는 비용**이다 — 부원 셸 호출의 16%
  가 한글이 깨진 채 모델에게 가고, 편집 열에 하나가 헛돈다.
- 남은 진입 관문은 하나 — DB 허용 목록. 운영자는 그것을 없애기로 했다(Now N3).
- 이 판은 **두 축**을 담는다. 축 A = 쓰는 사람 모두의 마찰(진행 가시성·제어·출력 품질 — 운영자가 1차
  보고자지만 같은 진행 표시·같은 얇은 워커 경로를 부원도 겪는다). 축 B = 부원의 진입·권한·경로.
- 우선순위는 추측이 아니라 실측으로 정한다. 이 갱신이 [관측 설계](../superpowers/specs/2026-07-28-observability-for-club-open-design.md)
  §9 가 미뤄 둔 M2 결정 지점의 첫 실행이다.
